# 07 - Cuenta regresiva

Cinco segundos de cuenta atras en la consola.

```bash
python 07-CuentaRegresiva/main.py
```

`end=""` hace que el numero se escriba sobre la misma linea en vez de dejar una
debajo de otra, y `flush=True` es lo que hace que se vea al instante: sin eso
Python guarda la salida en un buffer y todo aparece junto al final.
