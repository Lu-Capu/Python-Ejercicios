# 05 - Bisiesto

Dice si un ano es bisiesto o no.

```bash
python 05-Bisiesto/main.py
```

Usa las reglas del calendario gregoriano: divisible entre 4, salvo que sea
divisible entre 100, y entonces solo si ademas es divisible entre 400. Por eso
1900 no es bisiesto pero 2000 si.

Los anos de 1582 para atras se rechazan, porque el calendario gregoriano empezo
ese ano.
