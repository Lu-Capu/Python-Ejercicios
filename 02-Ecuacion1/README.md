# 02 - Ecuacion 1

Evalua `y = 3x^3 - 2x^2 + 3x - 1` para varios valores de x.

```bash
python 02-Ecuacion1/main.py
```

Introduces los valores de uno en uno y escribes `fin` para ver los resultados.
Cada x se guarda en una lista y al final se imprime una linea por cada uno con su
y al lado.

Si escribes `fin` sin haber metido nada, el programa te avisa y sigue pidiendo. El
`.strip()` esta para que un espacio de mas al escribir `fin` no rompa la
comparacion.
