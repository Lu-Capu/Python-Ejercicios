# 10 - Listas

Practica de las operaciones basicas sobre una lista.

```bash
python 10-Lista/main.py
```

Pides tres integrantes, luego unos cuantos mas, borras los dos ultimos con `del`
y metes uno nuevo al principio con `insert(0, ...)`. Va mostrando la lista en
cada paso para que se vea que hace cada operacion.
