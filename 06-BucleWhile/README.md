# 06 - Bucle while

Adivina el numero secreto usando un `while`.

```bash
python 06-BucleWhile/main.py
```

El numero es el 777 y esta escrito en el codigo, asi que mas que un juego es un
ejercicio de bucle. Escribe `0` para salir antes de adivinar.

El `try` va dentro del bucle a proposito, para que un valor no numerico no termine
el programa.
